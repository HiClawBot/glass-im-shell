# Release Checklist

Use this checklist before publishing the repository or a package.

## Positioning

- Project name is `Glass IM Shell` or another original generic name.
- Description says `inspired by common messaging app patterns`.
- Public copy does not claim parity with, replacement for, or compatibility with any named third-party product.
- Screenshots show only this original UI and fictional data.
- README preview and release images come from `docs/assets/` or `output/smoke/` generated by this repository.

## Assets

- No third-party logos, official screenshots, official icon files, product artwork, app-store screenshots, or copied marketing graphics.
- CSS glyphs and UI marks are project-authored.
- `docs/RELEASE_ASSETS.md` describes the README preview and smoke screenshot workflow.
- Profile names, avatars, groups, messages, balances, and media labels are fictional.
- No real celebrity names, likenesses, endorsements, or brand relationships.

## UI Boundary

- Keep information architecture generic: chats, contacts, explore, profile, wallet, settings.
- Do not copy distinctive product colors, official icon shapes, splash screens, empty states, or exact copy.
- Avoid product-specific feature names in docs and UI labels.
- Keep wallet visuals and social/video flows original even when they follow common app conventions.
