# Local Preview

Use this document for local review and human acceptance.

## Canonical Ports

Local preview uses ports `5500-5509`.

Do not use stale browser tabs from older local ports for acceptance. If a browser tab points at another local port, open one of the URLs printed by `npm run serve:local`.

## Start Preview

Run:

```bash
npm run serve:local
```

The command picks the first free port from `5500-5509` and prints the canonical URLs.

## Review URLs

When the command starts on `5500`, review:

- `http://127.0.0.1:5500/`
- `http://127.0.0.1:5500/mobile.html`
- `http://127.0.0.1:5500/mobile.html#page:pay`
- `http://127.0.0.1:5500/examples/npm-minimal.html`
- `http://127.0.0.1:5500/examples/vanilla.html`
- `http://127.0.0.1:5500/examples/host-api.html`

If another port is selected, keep the same paths on the selected port.

## Cache Reset

If a browser shows an old UI:

1. Use the URL printed by `npm run serve:local`.
2. Add a query string such as `?v=local-review`.
3. Refresh the page.
4. Confirm the URL uses a port from `5500-5509`.

## Mobile Deep Pages

The mobile phone preview forwards hash routes to the internal app frame. These routes should work:

- `mobile.html#page:pay`
- `mobile.html#page:payCode`
- `mobile.html#page:sendCrypto`
- `mobile.html#page:transfer`
- `mobile.html#page:swapCrypto`

## Acceptance Rule

Human acceptance should only use the canonical local preview command or screenshots generated by `npm run smoke:playwright`.
