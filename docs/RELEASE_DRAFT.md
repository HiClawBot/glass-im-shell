# Glass IM Shell 0.1.0

## Release Notes

Glass IM Shell 0.1.0 is a pre-Beta release of an original liquid-glass IM UI kit for generic messaging-style products.

This release includes:

- Fullscreen static prototype, phone preview, npm minimal host example, embedded host example, and host API example.
- Messages, contacts, explore, profile, settings, and global crypto wallet surfaces.
- Wallet flows for receive, pay, transfer, and swap using fictional display data.
- Chinese/English language switching, system light/dark adaptation, compact density, and host theme tokens.
- Runtime API through `window.GLASS_IM_CONFIG` and `window.GlassIMShell`.
- Stable host-facing API contract in `docs/API_CONTRACT.md`.
- TypeScript schema declarations in `schema.d.ts`.
- Release audits, architecture boundaries, mobile route matrix smoke checks, accessibility basics, and GitHub Actions verification.
- Beta readiness report covering capability status, verification evidence, release boundary, non-goals, and go/no-go conditions.
- Human acceptance checklist for screenshots, mobile flows, wallet mock surfaces, embedded mode, package contents, and release boundary review.
- Original README preview art and documented release asset workflow.

## Asset Boundary

- Release images must come from `docs/assets/` or screenshots generated by `npm run smoke:playwright`.
- Public screenshots should show only fictional data and original UI.
- Do not add third-party logos, official screenshots, copied icon files, copied product text, real public-person likenesses, or product-specific names.

## Package

The npm package preview is expected to list 53 files: source files, examples, schema, docs, audits, and original preview assets. It should not include local smoke output, browser logs, workflow files, dependency folders, or generated package archives.

## Known Scope

This release is a static UI kit and prototype shell. It does not implement a backend, real identity, real custody, real signing, live asset movement, notification delivery, or production data storage.
